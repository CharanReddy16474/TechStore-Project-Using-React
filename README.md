# 🛍️ TechStore – Modern E-Commerce Website

TechStore is a modern and responsive e-commerce web application developed using **React.js**. It provides an interactive shopping experience where users can explore technology products, search and filter products, manage their shopping cart, and maintain a wishlist.

The application features a clean user interface with dark and light themes, dynamic product filtering, and persistent cart and wishlist data using browser Local Storage.

## 🌐 Live Demo

**Live Website:** https://charan-techstore.vercel.app/

## 📂 GitHub Repository

**Source Code:** https://github.com/CharanReddy16474/TechStore-Project-Using-React

## ✨ Features

- **Product Listing:** Browse technology products with images, prices, ratings, and discounts.
- **Product Search:** Search products by name.
- **Brand Filtering:** Filter products based on available brands.
- **Product Sorting:** Sort products by price, ratings, and alphabetical order.
- **Shopping Cart:** Add and remove products from the shopping cart.
- **Quantity Management:** Increase or decrease product quantities.
- **Wishlist:** Add and remove favourite products.
- **Cart Summary:** Automatically calculate item quantities, subtotals, and total amounts.
- **Local Storage:** Persist cart and wishlist information using browser Local Storage.
- **Dark and Light Mode:** Switch between dark and light themes.
- **Responsive Design:** User-friendly shopping interface.

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/CharanReddy16474/TechStore-Project-Using-React.git
```

### 2. Navigate to the Project Directory

```bash
cd TechStore-Project-Using-React
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open the Application

Visit the local development URL displayed in your terminal:

```text
http://localhost:5173/
```
